1. CVisto
================================================================================

Project name: CVisto

Español:
Plataforma SaaS potenciada por IA que ayuda a los usuarios a crear perfiles estilo LinkedIn, analizar ofertas laborales con inteligencia artificial y generar CVs personalizados para cada postulación (exportables en formato DOCX), con seguimiento de postulaciones.

Desarrollé el frontend con React (Vite + TypeScript), utilizando Mantine UI para componentes, Zustand para manejo de estado y React Hook Form con Zod para validación. En el backend, implementé Node.js con Express e integración con la API de Google Gemini para análisis de ofertas y extracción de keywords. El sistema permite generar documentos DOCX dinámicos usando docxtemplater.

🔗 Repositorio: https://github.com/ericzager0/cvisto

English:
AI-powered SaaS platform that helps users create LinkedIn-style profiles, analyze job postings with artificial intelligence, and generate tailored CVs for each application (exportable as DOCX), with application tracking.

I developed the frontend using React (Vite + TypeScript), with Mantine UI for components, Zustand for state management, and React Hook Form with Zod for validation. On the backend, I implemented Node.js with Express and Google Gemini API integration for job posting analysis and keyword extraction. The system generates dynamic DOCX documents using docxtemplater.

🔗 Repository: https://github.com/ericzager0/cvisto

Skills: React, TypeScript, Node.js, Express, Google Gemini API, PostgreSQL, Mantine UI, Zustand, Docker, Git

3. Calcu - Scientific RPN Calculator
================================================================================

Project name: Calcu - Scientific RPN Calculator

Español:
Calculadora científica RPN/RPL con sistema de álgebra computacional. Calculadora de línea de comandos inspirada en las HP-48/HP-50g con notación polaca inversa y más de 560 operadores integrados.

Características: álgebra simbólica (derivadas, integrales, simplificación), cálculo numérico, estadística y regresión, teoría de grafos (80+ operadores), autómatas y lenguajes formales (DFA, NFA, CFG, PDA, máquinas de Turing), criptografía clásica y moderna, funciones financieras TVM, unidades físicas, plotting 2D/3D, y programación RPL.

Desarrollado en Rust utilizando Symbolica para el CAS, egui para GUI opcional, y aritmética de precisión arbitraria con GMP/MPFR.

🔗 Repositorio: https://github.com/Napero/calcu

English:
Scientific RPN/RPL calculator with computer algebra system. Command-line calculator inspired by HP-48/HP-50g with reverse polish notation and 560+ built-in operators.

Features: symbolic algebra (derivatives, integrals, simplification), numerical calculus, statistics and regression, graph theory (80+ operators), automata and formal languages (DFA, NFA, CFG, PDA, Turing machines), classical and modern cryptography, TVM financial functions, physical units, 2D/3D plotting, and RPL programming.

Developed in Rust using Symbolica for CAS, egui for optional GUI, and arbitrary precision arithmetic with GMP/MPFR.

🔗 Repository: https://github.com/Napero/calcu

Skills: Rust, Computer Algebra System, CLI Development, Algorithms, Data Structures

Currently working on this project: Yes
Start date: January 2025
